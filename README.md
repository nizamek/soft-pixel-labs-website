# Soft Pixel Labs website

Static public website for Soft Pixel Labs and CashSlate. It includes the product overview, support information, and the CashSlate privacy policy. It has no server-side code, sign-in, analytics, or user-data collection.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish with GitHub Pages

1. Push the site files to the repository's `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site. The public URL will be shown on that settings page.
5. Open the homepage, `/privacy.html`, and `/support.html` from a phone and desktop browser before submitting the URLs in Play Console.

The Privacy Policy page is intended to be the public policy URL for CashSlate. Confirm the developer contact and final policy details before publishing. Add the real Google Play listing URL to the homepage after the app is approved and available.

## Files

- `index.html` — studio and CashSlate landing page
- `privacy.html` — CashSlate privacy policy
- `support.html` — product support and common questions
- `styles.css` — responsive visual system
- `script.js` — accessible mobile navigation and small UI interactions
- `assets/cashslate-mark.png` — CashSlate app mark
